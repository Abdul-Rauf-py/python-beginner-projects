# Tic-Tac-Toe (GUI)

A two-player Tic-Tac-Toe game with a graphical window, built with Python and tkinter.

## Features
- Two players take turns as X and O
- Detects wins (all 8 lines) and draws
- Locks the board after the game ends
- Reset button to play again
- X is shown in pink and O in light blue

## How to run
1. Install Python 3.12 or newer from python.org
2. Download `tic_tac_toe.py`
3. Run: `python tic_tac_toe.py`

tkinter comes with the standard Windows installer, so nothing else is needed.

## What I practiced
- Building a grid layout with tkinter
- Connecting buttons to functions (callbacks)
- Tracking game state with variables
- Checking win conditions with logic
