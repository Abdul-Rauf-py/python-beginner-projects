# Python Beginner Projects

A collection of small Python programs I built while learning. Each project has its own folder with its own README.

## Projects

| Project | What it is | Concepts |
|---|---|---|
| [Contact Book](contact-book) | Terminal app to manage contacts, saved to a file | Functions, JSON, error handling |
| [Quiz Game](quiz-game) | Shuffled 5-question quiz with scoring | Nested loops, `random` module |
| [Bank Account (Terminal)](bank-account-terminal) | Multiple accounts with deposits, withdrawals and history | Classes, objects, searching a list of objects |
| [Bank Account (GUI)](bank-account-gui) | The same bank app in a window | tkinter, callbacks |
| [Tic-Tac-Toe](tic-tac-toe) | Two-player game with win and draw detection | tkinter grid layout, game logic |

## How to run any project
1. Install Python 3.8 or newer
2. Download the project's `.py` file
3. Run `python filename.py` in a terminal
